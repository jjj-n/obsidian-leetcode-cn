# 09 — 题解选择 UX：笔记 marker 吸收 + 命令 modal

**What to build:** 用户添加题解的两条路径：(1) 主路径——在笔记中任何位置写一行形如 `题解链接: <URL>`（或 `题解链接：<URL>`，容忍中英文冒号、前后空格）的 marker 行，运行"吸收题解链接"命令后，插件扫描当前笔记找到所有此类 marker 行，把每个 URL 自动吸收到最近的空 `<!-- lc:solution -->` 锚点（按参数匹配规则），然后触发抓取与内容填充；marker 行在吸收完成后被删除。(2) 辅助路径——命令面板打开 modal，用户输入或粘贴 URL，插件把它填到最近的空锚点并抓取。URL 格式不合法时温柔提示"URL 格式不对，请粘贴 leetcode.cn 题解链接"，不抛错、不修改笔记。

**Blocked by:** 07 — 多解法锚点（一题多 solution）

**Status:** ready-for-agent

- [ ] 笔记中出现 `题解链接: <URL>` 行时，"吸收题解链接"命令能扫描并识别所有 marker 行（容忍中英文冒号、空格、前后文本）
- [ ] 每个识别到的 URL 被填到最近的空 `<!-- lc:solution source=url url="" -->` 锚点参数里，并触发抓取填充
- [ ] 吸收完成后，原 marker 行被自动删除，笔记里只留下已填充的锚点
- [ ] 命令面板 modal 提供辅助输入路径：输入 URL → 填到最近空锚点 → 抓取
- [ ] URL 不合法（非 leetcode.cn 题解域名、无法解析出 slug 等）时 Notice 温柔提示，不修改笔记，不抛错
- [ ] 没有空锚点可吸收时，提示用户先添加一个空的 `<!-- lc:solution -->` 锚点或运行"新增题解锚点"命令
